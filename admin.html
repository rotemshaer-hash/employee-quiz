סרטונים

איך מעלים סרטון מהגלריה?
  1. בגלריה: בחר את הסרטון ← שיתוף ← Drive ← בחר את התיקייה מבחן עובדים ← שמירה.
  2. ב־Drive, כשההעלאה מסתיימת: ⋮ ליד הסרטון ← העתקת קישור.
  3. כאן: + הוספת סרטון ← הדבק את הקישור ← שמירה.
התיקייה משותפת פעם אחת ל"כל מי שיש לו את הקישור", וכל סרטון שנכנס אליה פתוח לעובדים אוטומטית.

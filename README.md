# מבחן עובדים

עובד צופה בסרטונים, מאשר שצפה, עונה על מבחן (אמריקאיות + פתוחות), והתוצאות נשלחות למייל של המנהל. העובד לא רואה ציון.

| קובץ | מה זה |
|------|-------|
| `index.html` | הדף של העובד. הקישור לכל מבחן: `index.html?t=<מזהה>` |
| `admin.html` | מסך הניהול: יצירה, עריכה, שכפול ומחיקה של מבחנים, וקישור לוואטסאפ |
| `settings.js` | חיבור ל־Firebase, ו־`demo` (מצב בדיקה) |
| `database.rules.json` | כללי מסד הנתונים — מודבקים בלשונית Rules של Realtime Database |
| `storage.rules` | כללי האחסון — מודבקים בלשונית Rules של Storage |
| `demo.js` | מצב בדיקה: שומר בדפדפן ומציג את המייל במסך הניהול במקום לשלוח |

- **מבחנים:** נשמרים ב־Firebase Realtime Database תחת `quizzes/<מזהה>`.
- **סרטונים:** הדרך הראשית היא העלאה מהגלריה ל־Firebase Storage. ההעלאה נעשית בחתיכות של 8MB וממשיכה מאותה נקודה אם הרשת נופלת. בסרטון כזה העובד חייב לצפות עד הסוף ולא יכול לדלג קדימה. הדרך המשנית היא קישור מ־Google Drive, שם כפתור "הבא" נפתח אחרי זמן המתנה.
- **שליחת תוצאות:** דרך FormSubmit. בהגשה הראשונה מגיע מייל אישור חד־פעמי.

## מבחן חד־פעמי

אחרי הגשה מוצלחת נרשם `submissions/<מזהה מבחן>/<שם מנורמל>`, והעובד לא יכול לעשות את המבחן שוב באותו שם.
המסד הוא מקור האמת, ולכן "לאפשר שוב" במסך הניהול מחזיר גישה גם באותו מכשיר.

## קישורים אישיים

לכל מבחן אפשר לייצר קישורים אישיים: `index.html?t=<מזהה>&c=<קוד>`.
הקוד נשמר תחת `invites/<מזהה מבחן>/<קוד>`, ובסיום ההגשה נכתב בו `used` ו־`name`.
קישור שנוצל כבר לא פותח את המבחן, וקוד שלא קיים מציג "הקישור לא תקין".
הקישור הכללי (בלי `c`) ממשיך לעבוד, ושם הנעילה היא לפי שם המשתתף.

# מבחן עובדים

מבחן הדרכה לעובדים: נושאים, סרטונים, מבחן, ותוצאות במייל. העובד לא רואה ציון.

| קובץ | מה זה |
|------|-------|
| `index.html` | הדף של העובד. קישור אישי: `index.html?t=<מזהה>&c=<קוד>` |
| `admin.html` | מסך הניהול: נושאים, סרטונים, שאלות, קישורים אישיים ומעקב הגשות |
| `settings.js` | חיבור ל־Firebase, ו־`demo` (מצב בדיקה) |
| `demo.js` | מצב בדיקה: שומר בדפדפן ומציג את המייל במסך הניהול במקום לשלוח |
| `database.rules.json` | כללי מסד הנתונים — מודבקים בלשונית Rules של Realtime Database |
| `storage.rules` | כללי האחסון — מודבקים בלשונית Rules של Storage |

## נושאים

מבחן בנוי מנושאים (`topics`). כל נושא: שם, סרטונים ושאלות.
הסרטון הראשון בנושא הוא ההסבר הראשי; השאר הם הסברים נוספים לאותו נושא.
בסוף כל סרטון העובד בוחר "הבנתי" (מעבר לנושא הבא) או "לא הבנתי" (ההסבר הבא באותו נושא).
המייל מדווח לכל נושא את הציון ואת מספר הסרטונים שהעובד נזקק להם.
מבחן ישן עם `videos`/`questions` שטוחים מומר אוטומטית לנושאים בפתיחה.

## נגינת סרטונים

סרטון שהועלה מהגלריה יושב ב־Firebase Storage ונטען ישירות. ההעלאה בחתיכות של 2MB וממשיכה אחרי נפילת רשת.
קישור Drive מנוגן קודם ישירות מ-`drive.usercontent.google.com`, ואם Drive חוסם — נופל לנגן המוטמע ולזמן המתנה.
בכל מקרה אי אפשר לדלג קדימה, והסרטון הבא נטען מראש ברקע.

## חד־פעמיות

- קישור אישי: `invites/<מבחן>/<קוד>`, נחסם אחרי הגשה.
- קישור כללי: `submissions/<מבחן>/<שם מנורמל>`, נחסם לפי שם.
במסך הניהול אפשר לראות מי הגיש, לפתוח מחדש למשתתף יחיד או לאפס הכול.

## עותק של התוצאות במערכת

כל הגשה נשמרת תחת `submissions/<מבחן>/<מפתח>` עם הציון לכל נושא וכל התשובות.
המפתח הוא `c_<קוד>` לקישור אישי, או השם המנורמל לקישור כללי.
לכן המסך "מי הגיש" מציג את התוצאות המלאות גם אם המייל נכשל או נמחק.
